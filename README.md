# Umalakshmi Receipt Desk

Donation receipt generator for Umalakshmi Educational Trust (Charitable Trust), Chennai.

Fill in the donor details and the receipt PDF downloads instantly, filled onto the trust's
official receipt template. The receipt register is kept in your browser on this device.

## Hosting
Enable GitHub Pages: Settings -> Pages -> Deploy from a branch -> main, root.
The form will be live at `https://<username>.github.io/<repo>/`.

Works on desktop and mobile browsers. Requires internet on first load.
